If you want to delete the wishes folder from Git and also delete it locally, run these CMD commands:

cd /d "D:\PW\KR\Dynamic Websites\HomeLoop"


git rm -r wishes


git status


git add .
git commit -m "Remove wishes folder"


git push
If you want to delete it from Git but KEEP the folder on your computer

Use:

cd /d "D:\PW\KR\Dynamic Websites\HomeLoop"


git rm -r --cached wishes


echo wishes/ >> .gitignore


git add .gitignore
git commit -m "Remove wishes folder from Git tracking"
git push

Use the second option if wishes is a local folder you still want to keep, but you don't want it included in future Git commits.
